# 2.0 格式变更

- 临时变量（Temp）的格式从 `temp.something[图层]` 变更为 `temp[图层].something`，以保持一致性。
- 挑战（Challenges）现在以对象形式保存，每个位置记录完成的次数。（这将导致旧存档失效。）
- 挑战和升级中的 `effectDisplay` 不再接受参数，可购买项（Buyables）中的 `effect` 也同样不再接受参数。
- 可购买项的成本可以接受一个参数表示购买数量，但必须能在无参数时正常工作（即计算下一次购买的成本）。
- 点数的生成现在在主游戏循环中完成（而非图层的更新函数中），通过 [game.js](js/game.js) 中的 `canGenPoints` 启用。
- `fullLayerReset` 更改为 `layerDataReset`，它接受一个需要保留的数值名称数组作为参数。

此外，许多名称也发生了变化，主要是将缩写展开：

所有出现以下缩写的地方：
- `chall` → `challenge`
- `unl` → `unlocked`
- `upg` → `upgrade`（CSS 除外）
- `amt` → `amount`
- `desc` → `description`
- `resCeil` → `roundUpCost`
- `order` → `unlockOrder`
- `incr_order` → `increaseUnlockOrder`

挑战相关：
- `desc` → `challengeDescription`
- `reward` → `rewardDescription`
- `effect` → `rewardEffect`
- `effectDisplay` → `rewardDisplay`
- `active` → `challengeActive`
